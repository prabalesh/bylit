# Changelog

All notable changes to this project will be documented in this file.

## [1.3.0] - 2026-03-11
### Added
- Advanced Split Bills: Split by Equally, Parts, or Percentage.
- Modern Settlement UI: Replaced alerts with a selection modal for picking the receiving account.
- Category-wise Transaction View: View all transactions for a specific category from Analytics and Categories screens.
- Enhanced Backup & Restore: Updated payload to include all tables and improved data integrity.

### Fixed
- Fixed notification permission handling for reminders.
- Smoothed out the app loading transition from splash screen to main app.
- Optimized loading screen animations for a more premium feel.

### Added
- CSV Backup and Restore functionality.
- Monthly Summary export via CSV.
- Developer details and version number in Settings screen.

### Fixed
- Modal background color issue in dark mode (white background above modals).
- Updated credits and versioning in settings.

## [1.0.0] - 2026-03-07
### Added
- Base version of the application.
- Dashboard widgets: Add Transaction, Monthly Summary, and Combined view.
- App walkthrough feature for new users.
- System theme support (automatic dark/light mode).
- Tablet responsiveness improvements.
- Credits in the application footer.

### Changed
- Modal positioning to improve user experience on mobile devices.
- Updated `app.json` for better device support and versioning.
