# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-03-07
### Added
- CSV Backup and Restore functionality.
- Monthly Summary export via CSV.
- Developer details and version number in Settings screen.

### Fixed
- Modal background color issue in dark mode (white background above modals).
- Updated credits and versioning in settings.

## [1.0.0] - 2026-03-07
### Added
- Base version of the application.
- Dashboard widgets: Add Transaction, Monthly Summary, and Combined view.
- App walkthrough feature for new users.
- System theme support (automatic dark/light mode).
- Tablet responsiveness improvements.
- Credits in the application footer.

### Changed
- Modal positioning to improve user experience on mobile devices.
- Updated `app.json` for better device support and versioning.
